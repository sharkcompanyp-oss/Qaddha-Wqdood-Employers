# تحويل النص إلى قالب JSON موحد

تستخدم هذه المهارة لتحويل الملخصات النصية أو المحاضرات إلى قالب JSON ثابت ومنظم، مع الالتزام الصارم بعدم تغيير أي حرف من النص الأصلي (لا زيادة ولا نقصان).

## القالب الموحد (JSON Schema)

يجب الالتزام بالهيكل التالي في جميع المخرجات:

```json
{
  "meta": {
    "lecture_title": "string"
  },
  "sections": [
    {
      "id": "string",
      "number": 0,
      "title": "string",
      "content_blocks": [
        {
          "type": "string",
          "emoji": "string",
          "text": "string",
          "label": "string",
          "title": "string",
          "badge": "string",
          "style": "string",
          "items": [
            {
              "text": "string",
              "keywords": ["string"],
              "is_example": false,
              "strong": "string",
              "emoji": "string",
              "title": "string",
              "description": "string",
              "type": "string",
              "items": [
                {
                  "text": "string",
                  "keywords": ["string"]
                }
              ]
            }
          ]
        }
      ],
      "notes": [
        {
          "student_ID": "",
          "student_nick_name": "",
          "note": ""
        }
      ]
    }
  ]
}
```

### الحقول المتاحة — شرح سريع

| الحقل | المستوى | الوصف |
|---|---|---|
| `meta.lecture_title` | جذر | عنوان المحاضرة كاملاً |
| `section.id` | section | معرّف فريد مثل `section_1` |
| `section.number` | section | رقم القسم (عدد صحيح) |
| `section.title` | section | عنوان القسم |
| `block.type` | block | نوع البلوك (انظر قائمة الأنواع أدناه) |
| `block.emoji` | block | إيموجي يُعبّر عن البلوك |
| `block.text` | block | نص مباشر للبلوك (للأنواع التي لا تحتاج items) |
| `block.label` | block | تسمية مختصرة للبلوك |
| `block.title` | block | عنوان داخلي للبلوك — **لا يُستخدم مع نوع `h3`** |
| `block.badge` | block | شارة نصية (مثل: "مهم"، "تنبيه") |
| `block.style` | block | نمط بصري (مثل: "warning"، "info"، "success") |
| `item.text` | item | النص الأصلي للعنصر |
| `item.keywords` | item | الكلمات المفتاحية المستخرجة |
| `item.is_example` | item | هل هذا العنصر مثال تطبيقي؟ |
| `item.strong` | item | جزء الجملة المراد تمييزه بخط عريض |
| `item.emoji` | item | إيموجي خاص بهذا العنصر |
| `item.title` | item | عنوان العنصر |
| `item.description` | item | وصف موسّع للعنصر |
| `item.type` | item | نوع فرعي داخل الـ items |
| `item.items` | item | عناصر متداخلة (مستوى ثالث) |
| `note.student_ID` | note | معرّف الطالب (تُترك فارغة) |
| `note.student_nick_name` | note | اسم الطالب (تُترك فارغة) |
| `note.note` | note | نص الملاحظة (تُترك فارغة) |

### أنواع البلوكات (block.type)

| النوع | متى يُستخدم |
|---|---|
| `paragraph` | فقرة نصية سردية متواصلة |
| `definition` | تعريف مصطلح أو مفهوم |
| `h3` | عنوان فرعي داخل القسم — **يستخدم `text` فقط، ولا يستخدم `title` أبداً** |
| `bullet_list` | قائمة نقطية بدون ترتيب |
| `process_list` | خطوات أو مراحل مرتّبة |
| `highlight_card` | معلومة بارزة تستحق التمييز |
| `info_box` | صندوق معلومات إضافية |
| `warning_box` | تنبيه أو تحذير |
| `two_column` | محتوى يُعرض في عمودين متوازيين |
| `items_grid` | شبكة عناصر (بطاقات) |
| `badge_card` | بطاقة تحمل شارة ونص |

## القواعد الأساسية
1. **الأمانة النصية**: لا تقم بتلخيص أو إعادة صياغة أو تصحيح النص الأصلي. يجب أن يظهر النص في حقول JSON تماماً كما ورد في المصدر.
2. **حقل الملاحظات (notes)**: اترك مصفوفة الملاحظات فارغة `[]` دائماً، فهي مخصصة لإدخالات المستخدم اللاحقة.
3. **أنواع البلوكات (content_blocks)**: استخدم النوع المناسب لطبيعة النص — وتنوّع بين الأنواع بشكل إلزامي (انظر قاعدة التنويع أدناه).
4. **الكلمات المفتاحية (keywords)**: استخرج **فقط** الكلمات ذات الأهمية العلمية أو التقنية الحقيقية من النص الأصلي. **لا تُكثر منها**، وتُترك فارغة إن لم يكن في النص ما يستحق التمييز. الإكثار من keywords يفقدها قيمتها وتأثيرها. **احتفظ بـ "ال" التعريف** في الكلمة المفتاحية كما هي في النص الأصلي (مثال: "الليزوزيم" وليس "ليزوزيم").
5. **عدم تكرار المحتوى بين الحقول**: يجب أن يكون محتوى كل حقل مختلفاً تماماً عن الحقول الأخرى في نفس العنصر:
   - **`title` و `text`**: لا يحملان نفس النص أبداً. `title` هو العنوان المختصر فقط، و`text` هو التفاصيل الموسّعة. إذا لم يكن هناك ما يميز أحدهما عن الآخر، **اترك أحدهما فارغاً ولا تكرر**.
   - **`block.text` و `item.text`**: إذا احتوى البلوك على `items` تحمل نفس المعلومة، فاجعل `block.text` مقدمة مختصرة مختلفة أو اتركه فارغاً. **يُحظر** نسخ نفس الجملة في `block.text` ثم إعادتها في `item.text`.
   - **`strong`**: يُشير فقط إلى الجزء الأهم للتمييز بخط عريض، وليس نسخة من `text` الكامل.
   - **`title` و `description`** في العناصر: `title` هو الاسم المختصر، و`description` هو الشرح. لا تضع نفس الجملة في كليهما.
   - **`keywords`**: لا تعيد ذكر كل كلمات `text` — اختر المصطلحات التقنية البارزة فقط.

## قاعدة التنويع الإلزامي في أنواع البلوكات

**يُحظر الاعتماد على نوع أو نوعين فقط من البلوكات في المخرج كله.** في كل قسم (`section`) من الأقسام، يجب أن يضم `content_blocks` مزيجاً متنوعاً من الأنواع. الهدف: أن يرى أي قارئ للـ JSON تنوعاً واضحاً في التمثيل البصري للمحتوى.

### دليل الاختيار — أيّ نوع يناسب أيّ محتوى؟

| نوع المحتوى في النص | أفضل نوع بلوك |
|---|---|
| تعريف مصطلح أو مفهوم | `definition` |
| عنوان فرعي أو تقسيم داخلي | `h3` |
| قائمة نقاط غير مرتّبة | `bullet_list` |
| خطوات أو مراحل متسلسلة | `process_list` |
| مقارنة بين جانبين أو عاملين | `two_column` |
| مجموعة بطاقات أو نظريات أو تصنيفات | `items_grid` |
| معلومة بارزة / استنتاج مهم | `highlight_card` |
| فقرة سردية أو شرح مطوّل | `paragraph` |
| تنبيه أو تحذير | `warning_box` |
| معلومة إضافية استكمالية | `info_box` |
| بطاقة بشارة نصية | `badge_card` |

### قواعد التنويع الصارمة

- **لا تكرر** نفس نوع البلوك أكثر من مرتين متتاليتين داخل نفس القسم.
- **في أي مخرج يضم 5 أقسام أو أكثر**: يجب أن تظهر على الأقل **7 أنواع مختلفة** من البلوكات عبر المخرج كله.
- **في أي مخرج يضم 3-4 أقسام**: يجب أن تظهر على الأقل **5 أنواع مختلفة**.
- **في أي مخرج يضم 1-2 قسمين**: يجب أن تظهر على الأقل **3 أنواع مختلفة**.
- قبل إنهاء المخرج، راجع ذهنياً: "كم نوع بلوك استخدمت؟" — إذا كان العدد أقل من المطلوب، أعد توزيع بعض البلوكات باختيار أنواع مختلفة تناسب المحتوى نفسه.

## أنماط يجب تجنبها (Anti-patterns)

### ❌ تكرار النص بين `block.text` و `item.text`
// خطأ: نفس الجملة في مكانين
{
  "type": "info_box",
  "text": "اكتشاف البنسلين عام 1928 بالمصادفة",
  "items": [
    { "text": "اكتشاف البنسلين عام 1928 بالمصادفة", "keywords": ["البنسلين"] }
  ]
}

// صواب: استخدم text فقط بدون items إذا كان المحتوى واحداً
{
  "type": "highlight_card",
  "text": "اكتشاف البنسلين عام 1928 بالمصادفة (فليمنغ)",
  "keywords": ["البنسلين", "فليمنغ"],
  "items": []
}

### ❌ تكرار النص بين `title` و `text`
// خطأ
{ "title": "هيالورونيداز: يحلل نسيج ضام", "text": "هيالورونيداز: يحلل نسيج ضام", "strong": "هيالورونيداز" }

// صواب: title مختصر، text مختلف — أو اترك أحدهما فارغاً
{ "title": "هيالورونيداز", "text": "يحلل النسيج الضام" }

### ❌ إكثار من keywords
// خطأ
{ "text": "الليزوزيم يكسر جدار الجراثيم", "keywords": ["الليزوزيم", "يكسر", "جدار", "الجراثيم"] }

// صواب: المصطلحات التقنية فقط
{ "text": "الليزوزيم يكسر جدار الجراثيم", "keywords": ["الليزوزيم"] }

### ❌ حذف "ال" التعريف من keywords
// خطأ
{ "keywords": ["ليزوزيم", "متمم", "سيتوكين"] }

// صواب
{ "keywords": ["الليزوزيم", "المتمم", "السيتوكين"] }

## مثال كامل (نص ونتيجة)

### النص المدخل:
**النخر السني (الجزء الأول)**

- النخر مرض خمجي جرثومي يصيب بنية السن، يؤدي إلى تحلل موضعي في النسج السنية المتكلسة وتخرب في مادته العضوية
- اللويحة الجرثومية: جراثيم ذات استقلاب نشيط ترتبط على سطح السن، تستقلب الكربوهيدرات وتنتج حموضاً تخفض pH الفم تحت 5 خلال 1-3 دقائق
- المعاب يخفف الحموض ويرفع pH مما يؤدي لإعادة تمعدن النسج
- حين تسبب محصلة انخساف الأملاح نقصاً حقيقياً في المعادن تحدث الآفة النخرية

**نظريات حدوث النخر:**
- نظرية توليد الحموض (Miller 1881): النخر على مرحلتين — انخساف أملاح الميناء ثم تخرب النسج الطرية، الحمض هو العامل المسبب
- نظرية تحلل البروتين (Heider & Bodecker 1919): الجراثيم تنتج أنزيمات حالّة للبروتين تسبب تخرباً في المواد العضوية، الميناء يحتوي 0.56% مواد عضوية + صفائح مينائية تشكل ممرات للجراثيم
- نظرية الاختلاب والتحلل البروتيني (Schutz 1955): تخريب جرثومي للمحتوى العضوي بالأنزيمات + تحلل للمحتوى اللاعضوي بالاختلاب في آنٍ واحد، الفلور يكوّن بلورات فلور أباتيت تقوي الارتباط بين المحتويين وتقلل احتمال التخرب

**مفهوم التوازن في النخر:**
- النخر نتيجة تفاعل بين عوامل ممرضة (جراثيم، نظام غذائي سيء، جفاف الفم) وعوامل دفاعية (المعاب، الكلورهيكسيدين، الفلور، سادات الوهاد، النظام الغذائي الفعّال)
- التوازن يتغير يومياً حتى عند الأصحاء

**العوامل الموضعية المسببة للنخر (3 عوامل):**

**1. الجسم المضيف:**
- سماكة الميناء ودرجة احتوائه على الفلور
- وجود وهاد وشقوق عميقة أو ضحلة
- وضع السن في القوس
- المعاب: دور وقائي (بروتينات تحمي من الحموض، مضادات جراثيم، إعادة تمعدن بالكالسيوم والفوسفات والفلور، تنظيف غريزي)

**2. النظام الغذائي:**
- الطبيعة الفيزيائية للغذاء تؤثر في حدوث النخر (الصلب يساعد التنظيف الغريزي، الرخو اللاصق يزيد النخر)
- السكاكر الأحادية والثنائية تسبب نخوراً أكثر من عديدات السكاكر
- وجود بروتينات ودسم مع الكربوهيدرات يجعلها أقل تأثيراً
- pH يعود للاعتدال بعد 30-60 دقيقة؛ التناول المستمر يمنع العودة للاعتدال + تواتر التناول أهم من كميته
- منحنى Stephan: pH ينخفض لـ 5.5 و 5.2 بعد الكربوهيدرات
- الأغوال السكرية (Sorbitol, Mannitol, Xylitol) لا تستقلب من الجراثيم + تأثير خافض للنخور
- Vitamin D: نقصه + نقص تصنع الميناء، إعطاؤه للأطفال يساعد في تشكيل أسنان سليمة
- Vitamin B6: دور مضاد للنخور
- Vanadium في ماء الشرب: ارتفاع تركيزه + انخفاض النخر
- Selenium: ارتفاع تركيزه + ارتفاع النخر

**3. الجراثيم:**
- لا تظهر آفات نخرية إذا كانت حفرة الفم خالية من الجراثيم
- المكوريات العقدية المطفّرة (S. mutans): الأخطر، تلتصق بالأسطح، تنتج حموضاً كبيرة، تبقى عند pH منخفض، مسؤولة عن نخور السطوح التاجية
- Actinomyces Viscosus: المسبب الأساسي للنخور الجذرية
- Lactobacillus Acidophilus: ارتفاع نسبته في المعاب يزيد احتمال النخور
- يمكن انتقال الجراثيم من الأم للجنين

**4. الزمن:** الجراثيم تحتاج وقتاً لطرح الحموض، والحموض تحتاج وقتاً لخسف الأملاح

**تصنيف النخور السنية:**

**أولاً: بحسب المكان التشريحي:**
- نخور الوهاد والميازيب: تصل للملتقى المينائي العاجي وتتجاوزه، تبدو بشكل مخروطين قاعدة لقاعدة
- نخور السطوح الملساء: تبدأ في المناطق الملساء (السطوح الملاصقة)، مخروط قاعدته على السطح المينائي وذروته نحو الملتقى المينائي العاجي
- نخور السطح الجذري: عند انكشاف الجذر، أسرع من أشكال النخور الأخرى، تزداد عند كبار السن مع انحسار لثوي

**ثانياً: بحسب كون الآفة أصلية أو ناكسة:**
- نخور أولية: آفات بدئية في بنية السن
- نخور ثانوية (ناكسة): تحدث في المسافة البينية بين السن والترميم أو تحته، تشير لوجود تسرب مجهري
- نخور متبقية: تبقى بعد التحضير (متعمدة أو طارئة)، يُسمح بإبقاء العاج المتأثر Affected عند قرب المعاب

**ثالثاً: بحسب سرعة الآفة:**
- نخور حادة: أذية سريعة، طرية، تلون خفيف
- نخور جائحية (Rampant): أكثر من 10 آفات جديدة عند نفس المريض خلال عام، تترافق مع صحة فموية سيئة أو نقص المعاب، تشمل:
  - نخر الطفولة المبكرة: يصيب الأسنان المؤقتة
  - تناذر الرضاعة من الزجاجة: القواطع العلوية، بسبب الحليب المحلّى والنوم مباشرة
  - نخور المراهقين: تناول متكرر للسكاكر مع إهمال الصحة الفموية
  - نخور جفاف الفم (Radiation Caries): بسبب تأذي الغدد المعابية بالأشعة
- نخور مزمنة: بطيئة أو متوقفة، صلبة ومتلونة

**رابعاً: بحسب فعالية النخر:**
- نخر فعّال: آفات بيضاء باهتة مغطاة باللويحة، سطح خشن
- نخور متوقفة (غير فعّالة): تشكلت وتوقفت عن الانتشار

**خامساً: بحسب سير الآفة:**
- نخور متقدمة: مخروط الميناء أكبر من مخروط العاج أو يساويه
- نخور راجعة: النخر يتجاوز الملتقى المينائي العاجي ويمتد إلى الميناء المجاور

**سادساً: بحسب عدد السطوح المصابة:**
- بسيطة: سطح واحد
- مركبة: سطحان
- معقدة: ثلاثة سطوح أو أكثر

**سابعاً: بحسب تصميم المعالجة (تصنيف Black):**
- الصنف I: نخور الشقوق والوهاد
- الصنف II: السطوح الملاصقة للأسنان الخلفية
- الصنف III: السطوح الملاصقة للأسنان الأمامية دون الزاوية القاطعة
- الصنف IV: السطوح الملاصقة للأسنان الأمامية مع الزاوية القاطعة
- الصنف V: الثلث المثوي للسطوح الدهليزية واللسانية لجميع الأسنان
- الصنف VI: الحدود القاطعة للأسنان الأمامية ورؤوس الحدبات للخلفية

**ثامناً: التصنيف العياني (للسطوح الإطباقية):**
- 0: لا تغير
- 1: ظلالية ضوئية صعبة التمييز على السطح الرطب، واضحة بعد التجفيف
- 2: ظلالية واضحة بدون تجفيف
- 3: تهدم مينائي محدود
- 4: حفرة واضحة ممتدة حتى العاج

**تاسعاً: تصنيف WHO (شكل وعمق الآفة):**

الدرجات السريرية:
- 1D: آفات مينائية كاشفة سريرياً مع سطح سليم
- 2D: تجويف ضمن الميناء
- 3D: تجويف ضمن العاج
- 4D: الآفة تصل المب

الدرجات الشعاعية:
- E0: لا دليل شعاعي
- E1: الآفة في النصف الخارجي من الميناء
- E2: الآفة في النصف الداخلي من الميناء
- D1: الآفة في الثلث الخارجي من العاج
- D2: الآفة في الثلث المتوسط من العاج
- D3: الآفة في الثلث الداخلي من العاج

### النتيجة (JSON):
```json
{
  "meta": {
    "lecture_title": "النخر السني (الجزء الأول)"
  },
  "sections": [
    {
      "id": "section_1",
      "number": 1,
      "title": "تعريف النخر السني واللويحة الجرثومية",
```
